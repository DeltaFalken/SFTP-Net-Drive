# SFTP-Net-Drive
A programm that allows to mount SFTP locations as Windows SMB Network drives.

The programm is fully generated by a LLM, by a very unexperienced developer. This means: it works completly fine, but is probably not 100% safe.

# Installation
1. You need to install the dependecy Dokany https://github.com/dokan-dev/dokany/ first.
2. Download SftpNetDrive.exe from the Releases page of this repository: https://github.com/DeltaFalken/SFTP-Net-Drive/releases
3. Run through the Installer wizard and reboot the system.
4. Enter the Windows Explorer and add a new network drive: \\SftpNetDrive\[Username]@[network address]![port]\[subpath]
5. Enter username and password into the authentification wizard.
